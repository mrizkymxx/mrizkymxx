IT Support & Web Developer — Jepara, Jawa Tengah.

Orang yang dipanggil kalau printer di kantor macet. Di luar itu, yang saya kerjakan: membangun dan memelihara sistem yang beneran dipakai — aplikasi desa, sistem antrean, sampai manajemen produksi pabrik karton.

## Proyek

- **Lapor Desa Rau** — aplikasi pengaduan warga untuk Desa Rau. Laporan divalidasi GPS (radius 2 km dari balai desa) pakai PostGIS, supaya laporan tidak bisa asal masuk dari luar wilayah.
- **Q-Premium Queue** — antrean realtime: kiosk mandiri di lokasi, warga pantau nomornya dari HP tanpa pasang app. Flutter + Supabase Realtime.
- **BSMCartonBox** — manajemen produksi pabrik karton: order masuk, planning produksi, laporan harian. Next.js + Firestore.
- **EximPro** — tracking shipment ekspor-impor: status kontainer, dokumen, jadwal stuffing.
- **Digital Loyalty Card** — poin loyalitas untuk coffee shop, klaim reward pakai QR.
- **Mebel Pak Sugiono** — halaman jualan mebel jati solid Jepara.
